# MFM Teenage Church — North Central Region 7

Official website of the MFM Teenage Church, North Central Region 7, Gwagwalada, Abuja.

**Motto:** Raising Champions for Christ

Built with React, TypeScript, Vite, Tailwind CSS, Framer Motion and React Router.

## Development

```bash
npm install
npm run dev
```

## Validation

```bash
npm run lint     # oxlint
npm run build    # tsc -b && vite build
```

## Production build

```bash
npm run build    # outputs to dist/
npm run preview  # serve the production build locally
```

## Content

All site content (programmes, activities, ministries, messages, contact details) lives in
[`src/data/content.ts`](src/data/content.ts). Placeholder visuals are used until official
photos and programme flyers are available.
